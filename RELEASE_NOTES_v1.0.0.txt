# Open Editor v1.0.0

The first public release of Open Editor, a non-linear video editor written from scratch in C++ with Qt 6 Widgets. It covers timeline editing, color, audio and local speech-to-text, and it includes an MCP server that lets AI clients drive the editor.

## Highlights

- **Edit video by editing text.** Transcribe a sequence on your own computer with Whisper, then delete words in the transcript to cut that footage from every track. Captions, markers and links follow, and Undo restores it all.
- **Full editing workspace.** Eight workspaces cover assembly, editing, color, effects, audio, graphics, text and AI.
- **AI that works through normal undo.** Connect an MCP client to 45 editor tools, or use the built-in AI Assistant with your own Claude API key.
- **Extensible.** Write native video and audio effects with a small C plugin API.

## Features

### Editing
- Multi-track timeline with razor, ripple delete, trim to playhead and linked clips
- Nested sequences, markers and paste attributes
- Multicam editing, with each video track as a camera angle
- Time remapping and speed changes

### Effects and compositing
- 40 effects: 29 video and 11 audio
- 18 transitions: 15 video and 3 audio
- 13 blend modes
- Chroma and luma keying, adjustment layers and titles
- Keyframes with linear, hold and ease interpolation

### Color
- Color Grade with temperature, tone, lift, gamma, gain and vignette controls
- LUT support
- Luma waveform, RGB parade, vectorscope and histogram
- PQ and HLG sources tone mapped to Rec.709

### Audio
- Track mixer and audio meters
- Clip and track effects, including compressor, limiter, parametric EQ, delay and reverb
- Constant power, constant gain and exponential crossfades
- Audio normalization

### Transcription and captions
- Local Whisper transcription, with Large v3 Turbo as the default model
- Models download once, after you confirm
- Word timing refined against measured speech regions and energy dips
- Click a word to jump to it, or select words and press Delete to cut them

### AI
- MCP server over Streamable HTTP on `127.0.0.1`, with bearer token auth and cross-origin requests refused
- `oe-mcp.exe` stdio bridge for clients that launch a local command
- AI Assistant panel using the Claude Messages API
- Remove silence, scene edit detection and audio normalization from the AI menu

### Performance
- GPU effects, tested against CPU output
- Proxy workflow

### Export
- **Delivery:** H.264, HEVC (H.265), VP9 (WebM), AV1
- **Mastering:** ProRes 422, ProRes 4444, DNxHR HQ
- **Hardware:** H.264 and HEVC with NVIDIA NVENC, H.264 with Intel Quick Sync, H.264 with AMD AMF, listed when the encoder works on your machine
- **Audio only:** WAV, MP3, AAC
- **Other:** Animated GIF

## Requirements

- Windows
- FFmpeg 8 or newer with the `whisper` filter: `ffmpeg` and `ffprobe` on `PATH`, or `ffmpeg.exe` and `ffprobe.exe` beside `OpenEditor.exe`

To build from source, you also need:

- Qt 6.10 or newer (developed with 6.11.1 MinGW 64-bit)
- CMake 3.21 or newer
- A C++17 compiler

Open `CMakeLists.txt` in Qt Creator, or run `./build.sh` from a POSIX shell. See the README for details.

## Privacy and safety

- Transcription runs on your computer. Whisper models are downloaded once, after you confirm.
- The MCP server is off by default and listens only on `127.0.0.1`.
- The AI Assistant sends project details, transcripts and any frames it inspects to the Claude API. Your API key is encrypted for your Windows user.
- Plugins run inside the editor process, so install only ones you trust.
